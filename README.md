# 👕 Amazon Apparel Price Tracker

An automated Python data pipeline that scrapes Amazon T-shirt names and prices daily, tracking historical trends by appending data to a structured Pandas DataFrame.

---

## 🚀 Features
* **Automated Daily Scrapes:** Runs automatically every 24 hours to capture real-time market data.
* **Robust Scraping:** Extracts product names, current pricing, and timestamps from Amazon search results.
* **Persistent Storage:** Automatically structures data into a Pandas DataFrame and appends it to a historical CSV database without overwriting past entries.

---

## 🛠️ Tech Stack
* **Language:** Python 3.x
* **Libraries:** BeautifulSoup4, Requests, Pandas, Time
